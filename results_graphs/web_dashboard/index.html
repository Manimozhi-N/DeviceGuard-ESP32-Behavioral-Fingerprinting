About the Project

ESP32-based behavioral device fingerprinting

Project Objective

Analyze Wi-Fi traffic characteristics such as packet size, inter-arrival time, and frame frequency to investigate device identification using machine learning.

Technology Stack

ESP32, Python, Random Forest, scikit-learn, CSV data logging, HTML, CSS, JavaScript, and Chart.js.

Machine Learning

The trained model predicts the device classes represented in its training data. Confidence is a model score and does not guarantee prediction accuracy.

Current Limitation

This page reads a CSV file selected by the user. It does not receive live ESP32 data or independently verify whether a device is unauthorized.
